Main Work

Gesture Demo: Real-time Hand Gestures

Recognizes 15 hand gestures from a webcam in real time and drives interactions (pinch, grab-and-drag, drawing, image and sound triggers), with a self-collected dataset and a self-trained model.

My Role

  • Solo project: architecture, data collection, model training, evaluation and interactions

Results & Highlights

  • 15 gesture classes, 95.73% test accuracy, 33,809 self-recorded samples
  • Modular pipeline camera → detector → smoother → recognizer → interaction → renderer, connected only through data contracts
  • Rule-based and ML recognizers can be switched live for side-by-side comparison
  • Limitations documented honestly: thumb_up recall is only 0.75

Challenges & Solutions

  1. 01

    Challenge

    Hand-written geometric rules break as soon as the hand rotates (for example, a thumbs-up).

    Solution

    Replaced them with a self-trained MLP classifier. Thanks to contract-based isolation, only the recognizer file changed; no other module was touched.

  2. 02

    Challenge

    Hand position and distance change the features a lot, and the depth coordinate is noisy.

    Solution

    Normalize by subtracting the wrist and dividing by palm size; z hurt accuracy in tests, so only x and y are used.

  3. 03

    Challenge

    Consecutive frames are nearly identical, so a random split inflates test accuracy.

    Solution

    Stratified split by whole recording session to prevent data leakage.

  4. 04

    Challenge

    Two identical runs differed by about 1%, making it impossible to tell whether a change helped.

    Solution

    Seeded all three sources of randomness (split, weight init, DataLoader shuffle) for bit-identical weights, and logged config, git commit and data hash on every run.

  5. 05

    Challenge

    Some gestures were confused with each other.

    Solution

    Targeted re-recording guided by the confusion matrix raised F1 for three gestures from 0.73/0.79/0.83 to 0.97/1.00/0.99.
