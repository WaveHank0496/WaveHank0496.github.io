東澳 EIA 在地集點系統

串連宜蘭東澳 10 家在地商家的集點活動：掃店家 QR 蓋章，集滿 3 家用扭蛋機兌換，附東澳飛魚主題小遊戲。

我負責的部分

  • 系統設計與開發（與 AI 討論設計，Claude Code 輔助實作），起源於課程專案
  • Cloudflare Workers 後端 API、前端集點卡、兌換加密與安全防護
  • 自己整理威脅模型：SSRF、CORS、偽造兌換與已知取捨

成果與重點

  • 累積瀏覽 1,657 次、參與集點遊戲 420 人次
  • 無伺服器架構，8 支 API，沒有源站主機
  • 跨裝置用卡號還原進度、偵測 LINE／Facebook 內建瀏覽器、中英雙語
  • 匿名流量來源統計（NFC、店家 QR、直接進站）與問卷彙總

技術難點與解法

  1. 01

    難點

    使用者可以改前端程式，偽造自己集滿點數。

    解法

    兌換資格一律由後端從資料庫重算，完全不信任前端傳來的數字。

  2. 02

    難點

    兌換 QR 被截圖分享或重複使用。

    解法

    兌換 QR 用 AES-256-GCM 加密並帶簽發時間，由扭蛋機端解密驗證。

  3. 03

    難點

    公開 API 容易被濫用或灌資料。

    解法

    依 IP 速率限制（10 秒 50 次）、輸入白名單驗證，機密只放在平台的 secret 設定、不進版控。
